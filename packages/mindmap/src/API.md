# Shared mind map contracts

All logic in this package is host independent. Public commands operate on immutable models; the caller owns saving, undo, collaboration, images, coordinates and UI.

- `applyMindmapCommand(object, command)` returns the final object, selection, removed references and invalidation. A locked map is unchanged. Paint-only patches and professional colors/line patterns do not perform text measurement or layout. Professional label, range and path changes report `geometry`, update only their derived bounds and retain saved tree sizes and relative positions; they do not run automatic tree layout.
- `buildMindmapTreeIndex` and `normalizeMindmapSelectionRoots` derive structure from persisted `order`; derived state is never serialized.
- `MindmapEditSession` isolates a text/new-node draft. An unchanged draft returns the latest model without measuring, laying out or creating history. Commit replays changed text on the latest target, and never revives a deleted node; changes to the same text or rich ranges while editing cancel the commit so hosts can report the conflict.
- `resolveMindmapProfessionalEdit(latest, baseline, draft)` rebases an existing summary, boundary or relation by changed fields. Unchanged drafts and converged edits are `noop`; unrelated latest fields survive, same-field conflicts are `conflict`, and removed objects are `missing`. Hosts validate permissions and node references and distinguish explicit creation from editing an existing object.
- `moveMindmapBranchesBetween` / `splitMindmapBranches` preserve node IDs except collisions, scaled explicit values, resources and transforms. The host redirects its external connectors using `ownerChanges` and converts `externalRelations` into native connectors, then commits every affected object once.
- `resolveMindmapDropIntent` accepts screen-space rectangles. Hosts provide coordinates and layout axis. `resolveMindmapSplitCandidate` implements the padded-map/64px split threshold.
- `resolveMindmapRenderData` provides geometry, style, wrapped lines, aligned text runs, image placement, decorations and professional paths. Text runs are relative to `content.label`; the host adds the node/body origin. Branch descriptors include the resolved color, inherited by descendants of each colored top-level branch. Relation arrow paths are supplied by the core.
- `configureMindmapTextMetrics` injects a host measurer. Increment its revision or call `invalidateMindmapTextMetrics` after font loading. Caches are bounded or weak. `clearMindmapCaches` clears text caches and invalidates weak render/layout cache revisions.
- Reading any saved node retains its persisted dimensions and coordinates, including auto-width nodes and after font registration. Explicit edits and automatic layout recalculate sizes. New auto-width nodes use a 320 logical pixel text-column limit. Hosts provide automatic content sizing without node width handles or width inputs. Editing a topic's text switches historical fixed-width nodes to automatic sizing; merely viewing or accepting unchanged text preserves their saved dimensions. Historical `textMaxWidth` values remain readable in scaled canvas units.
- `labelStyleRanges` use UTF-16 offsets snapped to grapheme boundaries. `replaceMindmapText` and `reconcileMindmapTextChange` preserve spans through edits. `parseMindmapHtmlText` extracts the supported inline formatting without retaining HTML.
- `MindmapExchangeCodec` validates and round-trips whole maps, forests and image resources. Invalid transforms, trees, theme snapshots and professional references are rejected before resource preparation or document mutation. `rootNodeIds` identifies the copied roots; Markdown parsing also returns it, distinguishing a synthetic forest center from a real topic with the same title. `pasteMindmapExchangeBranches` remaps IDs and imports the roots as children, or beside the optional insertion anchor. `duplicateMindmapObject` remaps all internal references. Markdown export escapes literal punctuation; supported formatting is reconstructed from styles rather than inferred from escaped label text.
- `searchMindmap` covers labels, descriptions and tags, including hidden nodes. `expandMindmapForSearch` is a temporary rendering model only; `replaceMindmapSearchMatches` returns one final document result.

No third-party editor, command history, DOM, React, Konva or Yjs runtime is imported here.
